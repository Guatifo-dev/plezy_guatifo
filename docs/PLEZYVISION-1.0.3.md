# PlezyVision 1.0.3 — Rediseño de las fichas de series y películas

Nueva versión estable de Plezy Vision para Fire TV (ARM32), probada y validada.

## Novedades
- Rediseño de las fichas de **series** y **películas**, con una presentación más amplia y cuidada de póster, fanart, logotipo, información e insignias audiovisuales.
- Ficha de series con fanart integrado y carrusel de episodios.
- Ficha de películas ampliada y fondo de Discover oculto detrás del panel.
- Botones de película organizados en tres filas, con más separación para facilitar la navegación con el mando.
- Sinopsis de películas limitada a diez líneas para evitar desbordamientos.
- Se conservan la reproducción de tráileres, las opciones y las personalizaciones de Plezy Vision.

**Código validado:** `71e5aa5a1f7fef41d79556a3a033bf829a86ee39`.

APK firmado para Fire TV ARM32; instalable como actualización sobre la versión anterior.
